## Features

- Multi-user contact management with BCrypt authentication and role-based authorization.
- 15+ REST APIs for contacts, profiles, dashboard, and assistant modules.
- Centralized exception handling using `@RestControllerAdvice`.
- Rule-based natural-language query assistant using JPA.
- CSV import/export with validation, duplicate detection, and row-wise reports.
- Parameterized JPQL search with category and favorites filters.
- User-specific dashboard with category-wise contact statistics.
