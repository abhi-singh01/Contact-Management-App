# UI Styling Update

The project keeps all existing backend features and adds a modern dashboard-style UI.

## Visual improvements
- Glassmorphism cards and soft shadows
- Indigo/cyan gradient hero section
- Contact cards with initials and category badges
- Dashboard statistics for contacts, favorites, family and work
- Cleaner search/filter/sort controls
- Responsive layout for smaller screens
- Redesigned login and registration pages
- No external CSS framework required

## Backend features retained
- Registration and Spring Security login
- CRUD contact operations
- Favorites
- Advanced search
- Categories
- Category filtering
- Sorting
- CSV export
